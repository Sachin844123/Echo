# Private research inputs

Place only documents you are authorized to use and your own labelled dataset
manifest here, or use a private directory elsewhere. Contents of this directory
are Git-ignored except this guide and the layout marker. Do not force-add private
documents, query text, relevance labels or run artifacts.

No research dataset is supplied. See [the dataset contract](../README.md) for
required fields, grading and tuning/test separation. Tiny synthetic verification
fixtures are generated in temporary directories by the tests, not stored here.
